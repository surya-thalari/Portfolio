# Thalari Surya Sai Ram — Portfolio Website

A professional corporate portfolio website built as a single self-contained HTML file.

## About

This portfolio showcases my skills, projects, experience, education, and certifications as a Full Stack Java Developer and Cloud Enthusiast. Designed with a Fortune 500-style corporate aesthetic using a deep navy and corporate blue color scheme.

## Features

- Single-file portfolio (all CSS and JS embedded — no build tools needed)
- Fully responsive for mobile and desktop
- Smooth scroll navigation with active link highlighting
- Typing animation in the hero section
- Scroll-triggered fade-in animations
- Clickable certificate cards linking to Google Drive
- Projects grid with GitHub links
- Contact section with email, phone, LinkedIn, and GitHub

## How to Open Locally

Simply open `index.html` in any modern web browser:

```
Double-click index.html
```

Or via command line:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

No server, no dependencies, no build step required.

## How to Deploy on GitHub Pages

1. Create a new GitHub repository (e.g., `portfolio` or `surya-thalari.github.io`).

2. Push this folder to the repository:

```bash
git init
git add .
git commit -m "Initial portfolio release"
git remote add origin https://github.com/surya-thalari/<repo-name>.git
git push -u origin main
```

3. Go to your repository on GitHub → **Settings** → **Pages**.

4. Under **Source**, select `Deploy from a branch` → choose `main` branch → `/ (root)` → click **Save**.

5. After a minute, your portfolio will be live at:

```
https://surya-thalari.github.io/<repo-name>/
```

If the repo is named `surya-thalari.github.io`, it will be available at `https://surya-thalari.github.io/` directly.
